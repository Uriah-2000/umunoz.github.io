Lesson 7 Summary Computer networks are systems that allow computers to communicate with each other to share information and resources. It is connected globally via TCP/IP which allows it to transmit data through various types of media. It can either be wired or wireless depending on the type of system. The first of the activities I researched and read through was through tutorial points and was about Internet Domain Name Systems. The DNS was made to help resolve when one downloaded a host file which contained names and files to their corresponding IP address which allows it to address. An IP address is a unique logical address which is assigned to a machine over the Internet and also is assigned to each host present on the internet. It's 32 bits which is over 4 bytes long and has two main components: a network and host components. A Uniform Resource Locator is a web address which identifies itself with a document on the internet and has two types Absolute and Relative. Absolute is a complete address which has server, path name and name file. Relative features are only partial of the web page and are easy to manage as Absolute is difficult to manage. The second activity as part of my understanding was from tutorials point and its topic was internet protocols. Internet Protocol itself is a connection-less and unreliable protocol in which it ensures no guarantee to successful transition of data. For it to work reliably it needs to be paired with TCP at the transport layer to work successfully. Also using a File Transfer Protocol (FTP) creates two processes Control Process And Data Connection which perform their respective functions. Also importantly the Trivial File Transfer Protocol is also used to transfer files but without authentication as TFTP lacks security and is not recommended. The last of my research was again on tutorials point and was about Internet Reference Models and what they are is a means of standardization which is acceptable worldwide. An OSI (Open Style Interface) is a model with seven layers such as Physical, Data Link, Network, Transport, Session, Presentation and Application. What surprised me was an important part of everyday use when we sign on to a computer is that Login and password checking are done by the application layer. The TCP/IP is a practical model used on the internet and is short for Transmission Control Protocol and Internet Protocol and what they both do together is combine the two layers into one host to network layer.
